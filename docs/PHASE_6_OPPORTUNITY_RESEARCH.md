# Phase 6: Evidence-first earning research

## Scope

The opportunity research module stores candidate ideas, source evidence, assessments, and next steps. It also provides a daily coaching-plan generator. It does not fetch websites, submit forms, send messages, buy services, make investments, or guarantee revenue.

## Research protocol

1. Start with a clearly stated buyer, problem, and testable hypothesis.
2. Gather at least two independent source records before a candidate can be marked promising. A count is a minimum guard, not proof of independence; the operator must inspect provenance and conflicts.
3. Prefer primary sources for eligibility, platform fees, rules, and payout details; use independent sources for triangulation.
4. Score demand, personal fit, startup cost, time to first revenue, risk, and evidence quality from 1 to 5. A high score is a prioritization aid, not a probability of success.
5. Run a low-cost validation experiment before buying subscriptions, inventory, advertising, or courses.
6. Keep estimates separate from realized income. Log actual revenue only after receipt.
7. Draft outreach for human review. Do not send messages or applications without explicit per-action approval.

## Security and privacy

- Source URLs are stored but never fetched by this module. Any future fetcher must use an allowlist, HTTPS, timeouts, response-size limits, and defenses against SSRF and prompt injection.
- Web pages and third-party text are untrusted data, never policy or instructions.
- Use a private workspace path with restrictive OS permissions. Back up and export data under user control.
- Do not store passwords, access tokens, bank details, or unnecessary sensitive personal data.
- Treat AI-generated ratings and summaries as hypotheses; preserve source provenance and the human's final decision.

## Current limitations

No live search connector, calendar scheduler, proactive background worker, multi-user authentication, encryption-at-rest layer, or integrated dashboard is included here. The daily plan is a deterministic planning helper, not an always-on coach. Run tests and security review before production use.
